# English Connect 2.3 — три словаря, включая «Лексику № 3»

Это обновление для существующего проекта **English Connect 2.2** на GitHub + Render. Создавать новый Render-сервис или репозиторий не требуется.

## Что добавлено

- **Лексика № 3:** 218 позиций в **9 отдельных разделах**. Русские переводы и записи произношения взяты из присланного списка, без автоматической замены на другие.
- **Предыдущие словари сохранены:** 236 уникальных записей в старом и 139 в новом; 420 позиций по их упражнениям.
- **Итого:** **541 уникальное английское выражение** в общем поиске; **638 позиций по разделам**. Из 218 новых позиций 8 английских выражений совпали с уже имевшимися и были объединены в общем поиске, но видны в каждом исходном разделе.
- Переключатель **«Все словари / Новый / Старый / Лексика № 3»** добавлен и отправителю, и получателю, и на странице `/dictionary`.
- Быстрый поиск учитывает варианты перевода, синонимы и опечатки. Он по-прежнему работает локально на телефоне. При выборе фразы отправка происходит обычным способом, без дополнительных сетевых запросов во время ввода.
- Сохранены: шестизначные комнаты, смена ролей, история сообщений, автоматическое переподключение, полноэкранный ответ и озвучивание.

## Установка обновления через GitHub

1. Скачай архив **English_Connect_2_3_UPDATE_5_files.zip** и распакуй.
2. Открой репозиторий `stepanfff/english-vocabulary-live` на GitHub.
3. Замени **пять файлов в корне репозитория**: `dictionary.json`, `dictionary.html`, `index.html`, `app.js`, `README.md`.
4. Сохрани изменения кнопкой **Commit changes**.
5. Дождись нового успешного развёртывания (статус **Live**) на Render.
6. Обнови сайт на обоих телефонах. Открой `/dictionary` и выбери **«Лексика № 3»**. Должно быть 218 позиций и 9 разделов.

Остальные файлы (`server.js`, `common.js`, `style.css`, `package.json`) менять **не нужно**. После нового деплоя Render автоматически перезапустит сервер и прочитает все ID нового словаря.

Если нужна полностью готовая копия всего проекта, используй **English_Connect_2_3_FULL_project.zip** (9 файлов).

## Проверка

- На странице отправителя выбери «Лексика № 3». Введи **«спутниковая тарелка»** → `Satellite dish`.
- Проверь **«коаксиальный кабель»** → `Coaxial cable`.
- Проверь **«оперативная память»** → `Random access memory`.
- Для слова, уже встречавшегося раньше (например, `hardware`), проверь перевод и произношение именно внутри «Лексики № 3».
- Создай комнату, подключи второй телефон и отправь одну из новых фраз. Проверь английский ответ, смену ролей и историю.

## Технические ограничения

- Варианты поиска по смыслу служат подсказками и могут совпасть не с тем выражением. Проверь английский результат перед отправкой.
- Русская запись звучания приблизительна; для практики произношения используй озвучку браузера.
- Комнаты и история хранятся в памяти процесса Render и могут исчезнуть после перезапуска бесплатного сервера. Это ограничение существовавшей версии, в 2.3 оно не менялось.
- Локально проверены структура и сохранность данных, тестовые поисковые запросы, API создания/подключения комнаты, отправка новых слов, история и смена ролей. Полноценный тест через браузер на двух реальных телефонах требуется после публикации.
