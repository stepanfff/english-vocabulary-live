# Словарь: два телефона + живые уведомления

В проекте **две основные страницы**:

- `/receive` — твой экран: входящие сообщения, всплывающие уведомления, поиск английских эквивалентов.
- `/send?room=...` — экран друга: ввод русской фразы и кнопка «Отправить».
- `/dictionary` — прежний полный HTML-словарь по страницам и упражнениям (236 уникальных записей, 266 с повторами).

Русские переводы, английские выражения и произношение перенесены из исходного HTML без изменения. Для работы между устройствами нужен **один работающий сервер**. Открытие отдельных `.html` файлов по двойному щелчку НЕ обеспечит связь.

## 1. Протестировать на компьютере

Потребуется **Node.js 20 или новее**.

1. Распакуй ZIP и открой терминал в папке, где находится `server.js`.
2. Выполни команду `npm start` (зависимости ставить не нужно).
3. Открой `http://localhost:3000/receive`.
4. Нажми «Скопировать» и открой полученную ссылку `/send?room=...` **во второй вкладке того же компьютера**.
5. Напиши русскую фразу, например «сложная сеть электронных цепей», и нажми «Отправить».
6. На `/receive` появится уведомление и будет показан английский вариант с транскрипцией.

**Для тестирования с двух телефонов** проще сначала разместить сайт в интернете, следуя инструкции ниже. `localhost` указывает на конкретное устройство и не будет работать на чужом телефоне. Альтернатива — запустить сервер на компьютере и использовать его LAN-IP, если устройства в одной Wi‑Fi сети и брандмауэр пропускает порт 3000.

## 2. Разместить сайт в интернете через GitHub + Render

1. Зарегистрируйся или войди на [GitHub](https://github.com/). Создай **новый репозиторий** (например `vocabulary-live`). Выбери **Private**, если не хочешь показывать учебный словарь и код публично.
2. Распакуй ZIP. На странице репозитория GitHub выбери **Add file → Upload files** и загрузи **все файлы из папки проекта**, не сам ZIP. Нажми **Commit changes**. Файл `server.js` должен находиться в корне репозитория.
3. Войди на [Render](https://dashboard.render.com/), выбери **New → Web Service** и подключи этот GitHub-репозиторий.
4. Укажи настройки:
   - Language / Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type / Plan: `Free` (если доступен)
5. Нажми **Create Web Service**. После развёртывания появится адрес вида `https://имя-проекта.onrender.com`.
6. Открой `https://имя-проекта.onrender.com/receive` на своём телефоне.
7. Нажми **«Скопировать»**, отправь ссылку другу в Telegram/WhatsApp. Он открывает именно эту ссылку, вводит фразу на русском и нажимает кнопку.
8. Оставь свою вкладку `/receive` открытой. Новые сообщения появятся в ней без обновления.

**Примечание про бесплатный Render.** Бесплатные сервисы могут засыпать через 15 минут без входящих запросов и просыпаться не сразу. При открытой странице получателя браузер делает редкие запросы, чтобы поддерживать соединение. Если вкладка закрыта или телефон надолго приостанавливает браузер, уведомления могут не прийти: *это не полноценный фоновый push*, и **офлайн-сообщения не сохраняются на сервере**.

## 3. Доступ и конфиденциальность

- Первая страница `/receive` автоматически создаёт случайный **ключ комнаты** из 32 шестнадцатеричных символов. Ключ включён в ссылку `/send`.
- Ссылка является общим секретом. Любой, кто получил её, может отправлять сообщения, а изменив путь `/send` на `/receive`, потенциально увидит сообщения комнаты. Не публикуй ссылку и не используй систему для личных данных.
- Сообщения передаются по HTTPS после развёртывания на Render. Сервер не ведёт историю сообщений; получатель хранит последние 25 сообщений только в браузере своего устройства.
- При перезапуске сервера офлайн-очередь не восстанавливается. При очистке данных браузера получателя может сгенерироваться новая комната. Тогда отправь другу новую ссылку.
- Для настоящих учётных записей, паролей и гарантированной доставки нужен отдельный сервис с базой данных и авторизацией.

## 4. Состав файлов

- `server.js` — HTTP + Server-Sent Events (без внешних библиотек)
- `package.json` — команда запуска
- `receive.html`, `receive.js` — экран получателя
- `send.html`, `send.js` — экран друга
- `common.js`, `style.css` — общие функции и оформление
- `dictionary.json` — 236 слов с привязкой к упражнениям
- `dictionary.html` — твоя прежняя полная версия словаря

Если нужен новый словарь, обнови `dictionary.json` и `dictionary.html`, сохраняя формат JSON.
