# English Connect 2.2 — оба словаря вместе

Теперь на сайте **два набора слов одновременно**, а не один вместо другого.

- **Новый словарь:** 139 уникальных английских выражений, 154 позиции в 7 подразделах (стр. 142–143, 156–157 и упражнения COMPUTERS / HARDWARE / MICROPROCESSOR).
- **Старый словарь:** 236 уникальных выражений, 266 позиций в 13 подразделах (стр. 135, 136, 137, 138, 156–157).
- **Совпадают по английскому написанию:** 44 выражения. Они объединены для поиска, но **сохранены в каждом своём разделе**.
- **Итого:** **331 уникальное выражение** в общем поиске и **420 позиций** в 20 подразделах.

У одинаковых английских выражений исходные русские переводы и записи произношения сохраняются для соответствующих разделов. Поиск учитывает оба перевода. Спорные варианты синонимов, как и раньше, лучше проверить перед отправкой.

## Что обновилось

1. На странице **Отправитель** новый переключатель «Все слова / Только новые / Только старые». Он ограничивает **только поиск**, без сетевых запросов.
2. На странице **Получатель** такой же переключатель для ручного поиска, а входящие сообщения по-прежнему отображаются и озвучиваются без фильтрации.
3. Страница `/dictionary` показывает все 20 подразделов; сверху можно выбрать словарь и упражнение. Повторяющиеся выражения отображаются в каждом исходном упражнении.
4. Сохранены старые функции: короткий код комнаты, обмен ролями, автоподключение, история последних сообщений, полноэкранный ответ, озвучка, исправление опечаток и синонимы.
5. **Серверная логика не изменялась.** Поиск выполняется на устройстве и не создаёт дополнительных HTTP-запросов при вводе.

## Обновление существующего сайта (рекомендуется)

1. Распакуй архив **English_Connect_2_2_UPDATE_6_files.zip**.
2. Открой репозиторий `stepanfff/english-vocabulary-live` на GitHub и перейди в **Add file → Upload files**.
3. Загрузи в корень репозитория 6 файлов с заменой предыдущих: `dictionary.json`, `dictionary.html`, `index.html`, `app.js`, `style.css`, `README.md`.
4. Нажми **Commit changes**.
5. Render автоматически пересоберёт сайт. После статуса **Live** обнови вкладки на обоих телефонах (если отображается старая версия, сделай полное обновление страницы).
6. На `/dictionary` проверь число **331 без повторов** и переключатель «Новый / Старый». На главной странице проверь отправку тестовых слов.

**Не удаляй** существующие `server.js`, `common.js`, `package.json`: они совместимы, менять их не нужно.

Если нужно восстановить проект целиком, используй **English_Connect_2_2_FULL_project.zip** (все 9 основных файлов).

## Что проверить на двух телефонах

- Создать комнату на одном, присоединиться на другом по шести цифрам.
- На отправителе выбрать **Старые** и найти `сложная сеть электронных цепей` → `an intricate network of electronic circuits`.
- Переключить на **Новые** и найти `вспомогательная память` → `auxiliary storage`.
- Отправить выражение, убедиться, что получателю пришёл ответ.
- Поменяться ролями, отправить второе выражение.

## Ограничения

Комнаты живут 2 часа, а их история хранится в памяти текущего процесса Render. Перезапуск бесплатного сервера может удалить активную комнату. Мобильные браузеры также могут приостанавливать фоновые вкладки; при возвращении включается существующее переподключение.
